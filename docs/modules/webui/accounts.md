# 实例账号管理

智能港区设置（`Alas` 任务页）提供账号管理面板。当前只支持国服 B 站客户端 `com.bilibili.azurlane`，必须配置明确的模拟器序列号，并提供 root ADB 或 `su` 权限。默认不访问游戏账号文件，不采集账号，也不恢复账号。

## 使用流程

1. 设置独立于 WebUI 密码的实例密码，至少 16 个字符且含至少 8 种不同字符，建议使用随机密码或长口令。
2. 停止使用同一模拟器的所有实例。在游戏中登录所需账号，输入实例密码，点击「备份当前游戏账号」。备份会停止游戏。
3. 如需保存其他账号，手动登录后再次备份。每个快照保存当时的登录状态。
4. 输入密码并查看账号，再输入密码点击所需快照的「切换并启动游戏」。切换前停止游戏，校验并恢复登录文件，然后启动游戏。登录凭据过期、风控验证或服务器要求重新登录时仍需人工处理。
5. 可启用「每次启动游戏前恢复选定账号」。未解锁时启动失败，不会绕过保险库使用设备上原有账号。不开启该开关时没有自动读取和写入。
6. Windows 主机可选择「绑定本机 TPM 自动解锁」。绑定成功后，服务重启和游戏启动可自动恢复账号。未绑定时，每次 WebUI 服务重启必须输入实例密码解锁。

账号身份只有在本次输入密码并点击查看之后才返回浏览器，60 秒后、切换页面或页面进入后台时隐藏。前端从不保存实例密码到浏览器存储，接口不返回登录 token、数据库内容或账号原密码。修改密码需要当前密码；删除当前选定快照会关闭启动恢复。删除实例也删除其账号保险库。

## 数据范围与设备一致性

已在授权模拟器检查数据库结构：`databases/users.db` 的 `users` 表包含登录凭据；Heart、track、Bugly 和 neuron 数据库是统计或错误上报数据，不作为账号快照。

快照包含 `users.db`、SDK 的 `shared_prefs/com.bilibili.azurlane_preferences.xml`，以及 Unity 的 `shared_prefs/com.bilibili.azurlane.v2.playerprefs.xml` 中 `user.*`、`server.id*`、`loginedServer_*` 登录字段。Unity 其他游戏偏好在恢复时保留。快照可能包含 SDK 历史登录账号；列表展示的是快照内身份，切换单位是整份登录状态快照。

采集前强制停止游戏并正向确认进程退出。遇到非空 SQLite WAL 或回滚日志拒绝采集，避免保存不完整事务。传输使用有超时的 ADB 标准输入/输出，不在主机创建明文数据库或 XML 文件。恢复在应用私有目录暂存和备份，保持应用 UID/GID、660 权限及 SELinux 上下文；恢复失败整组回滚。设备断连或回滚失败时，私有 `.azurpilot-account-*` 恢复目录可能被保留，需先人工确认原文件恢复状态再重试。游戏自动化 worker 与账号 API 共享父进程生命周期锁；启用账号管理时禁止同一模拟器同时运行多个受管理实例。独立启动的外部脚本不受 WebUI 进程登记管理，不应同时操作该模拟器。

## 加密与 TPM 的保护边界

`config/<实例名>/config.db` 是保存加密负载的 SQLite 容器，不是原样复制的游戏数据库。账号身份、快照名称和游戏文件一起使用 AES-256-GCM 加密并认证。每个保险库生成 2048 位（256 字节）随机盐并存入容器；使用 scrypt（N=2^17、r=8、p=1，约 128 MiB 内存成本）从实例密码派生 256 位密钥。每次保存生成新的 96 位随机 nonce；实例名、启用标记和 TPM 封装数据作为认证附加数据。密码不存储，密码校验通过密文认证完成，验证失败短暂限速。SQLite 旧页和回滚日志只包含密文。

AES 没有 2048 位密钥模式。2048 位在本功能中分别指随机盐长度和 TPM RSA 密钥长度。

TPM 绑定使用 Windows `Microsoft Platform Crypto Provider` 创建当前用户的不可导出 RSA-2048 私钥，以 RSA-OAEP-SHA256 封装保险库 AES 密钥。私钥保存在 Windows/TPM 的密钥存储中，项目只保存封装后的密钥。提供者或硬件不可用时明确失败，不回退到软件密钥。修改密码会重新封装新密钥；取消绑定移除保险库里的自动解锁封装，不销毁 Windows 中的私钥，以免影响已有加密备份。TPM 密钥名称绑定项目绝对路径和实例名，迁移路径、Windows 用户、设备或清除 TPM 后需使用密码重新绑定。

两种解锁路径并存：密码用于人工验证与迁移恢复，TPM 用于本机无人值守启动。复制全部项目文件到其他设备无法使用原 TPM 解锁，但仍可对密码做离线猜测，因此不能承诺弱密码无法破解。TPM 也不能阻止已控制原主机、拥有当前 Windows 用户权限的程序调用自动解锁或读取进程内存。浏览器密码门禁不是 TPM 对软件调用者身份的认证。远程账号操作要求 HTTPS/WSS；ADB、本机运行环境及已经恢复明文的 Android 游戏私有目录均须可信。

实现入口：`module/runtime/account_vault.py`、`account_tpm.py`、`account_device.py`，API 为 `accounts.status` / `accounts.manage`。所有敏感字段绕开普通配置和日志；异常只返回预定义消息，不打印底层 ADB 输出、密文解密内容或密码。
